# ⏱ Stopwatch Web Application

## 📌 Overview
This project is part of my **SkillCraft Technology Web Development Internship (Task 2)**.  
The goal was to build an **interactive and user‑friendly stopwatch** web application that allows users to accurately measure and record time intervals.

## ✨ Features
- ▶️ **Start**: Begin counting time
- ⏸️ **Pause**: Stop the timer without resetting
- 🔄 **Reset**: Clear the timer back to 00:00:00
- 🏁 **Lap Times**: Record and display lap intervals

## 🛠️ Tech Stack
- **HTML5** → Structure  
- **CSS3** → Styling & responsive design  
- **JavaScript (ES6)** → Stopwatch logic & interactivity
